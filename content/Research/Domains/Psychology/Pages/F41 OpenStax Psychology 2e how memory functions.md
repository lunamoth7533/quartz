## Key points (as published)

Memory is described through encoding, storage and retrieval, with sensory, short-term and long-term stores distinguished by capacity and duration.
^f41-three

Working memory models add active manipulation and executive control to the older short-term store, which is why rehearsal and load matter for performance.
^f41-working

Retrieval depends on cues and context, and forgetting is described through several mechanisms rather than a single decay process.
^f41-retrieval
