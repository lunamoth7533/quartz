## Key points (as published)

Memory is described in three processes - encoding, storage and retrieval - each with its own failure modes.
^f11-stages

Retrieval depends on cues and context, so availability is not the same as accessibility.
^f11-cues

Remembering is reconstructive: recall can be confident and still inaccurate.
^f11-reconstructive
