# Reinforcement learning and working memory in mood disorders: A computational analysis in a developmental transdiagnostic sample.

**Authors.** Cheng Z, Moser AD, Jones M, Kaiser RH (4 authors) · [PubMed record](https://pubmed.ncbi.nlm.nih.gov/37839471/)

**Published.** 2024 in Journal of affective disorders (first online 2023-10-13).
**Identifiers.** DOI [10.1016/j.jad.2023.10.084](https://doi.org/10.1016/j.jad.2023.10.084) · PMID [37839471](https://pubmed.ncbi.nlm.nih.gov/37839471/)

**Verification.** Abstract-level check via PubMed on 2026-09-27 (metadata matched by PMID). Full text was not read; read status is queued.

## Reported findings (checked abstract)

A combined reinforcement-learning and working-memory model, fitted to an instrumental learning task that varied memory load, showed faster working-memory decay and less use of working memory in participants with more severe current manic symptoms.
^p37839471-wm

Higher current anhedonia, and lifetime unipolar or bipolar diagnoses, went with lower reward learning rates; more severe current manic or anhedonic symptoms were associated with poorer task performance.
^p37839471-reward

## Scope as reported

Cross-sectional analysis of a developmental sample in a deterministic reward-learning paradigm; the authors state that parameters should be read within this task and population and call for replication in other paradigms and populations. The bipolar group is reported as bipolar disorders without subtype.
^p37839471-limit

## Library appraisal

These paragraphs are this library's own methodological appraisal, not statements from the paper.

The model separates working-memory from reward-learning contributions only within this task; with 28 participants in the bipolar group, diagnosis-level estimates are imprecise, and the state-versus-trait reading rests on cross-sectional associations.
