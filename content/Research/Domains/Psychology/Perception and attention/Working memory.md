# Working memory

## Definition

Working memory is the limited-capacity system that holds information in an active state while it is used. It includes both storage and manipulation, which distinguishes it from older short-term store models. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

## How it works

**A workspace, not a buffer.** Because working-memory models add active manipulation and executive control to the short-term store, the term describes a workspace in which information is maintained while being transformed - the difference between remembering a number and using it in a calculation - and capacity limits reflect control as well as storage. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

**It connects to the memory framework.** Memory is described through encoding, storage and retrieval, each with its own failure modes, and working memory is the active end of that system: what is held long enough to be manipulated. Retrieval also depends on cues and context, so availability is not the same as accessibility even for information currently in use. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]]

**Capacity limits are about interference, not slots.** Performance declines steeply as load increases, partly because representations compete and blur rather than because a fixed number of slots fills; similarity between items accelerates the decline, and consolidation into a durable form takes time during which new input interferes. That account predicts the counterintuitive findings - fewer, simpler items can be safer than many precise ones - and it links capacity to control: what survives interference depends on attention and strategy, not only on storage. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

**Control.** Updating, inhibiting irrelevant content and shifting between tasks are separable executive operations imposed on stored content. [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-finding|Beyond the dual pathway model]]

**Neural basis: prefrontal catecholamines.** Prefrontal and parietal regions are consistently implicated. Prefrontal function depends on noradrenaline and dopamine released according to arousal state, with an inverted-U relationship to performance, and the prefrontal cortex is critical for regulating attention, screening distractions, inhibiting impulses and planning - the biological account of why stress, arousal and medication change working-memory performance. [[P19621976 Arnsten 2009 Prefrontal catecholamines and ADHD#^p19621976-networks|Prefrontal catecholamines and ADHD]] [[P19621976 Arnsten 2009 Prefrontal catecholamines and ADHD#^p19621976-mechanisms|Prefrontal catecholamines and ADHD]]

**Working memory is not one thing clinically.** In the ADHD cognitive-profile study, temporal processing, inhibitory control and delay-related deficits behaved as independent components, which means a group difference on a working-memory task need not reflect a general capacity limit. [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-finding|Beyond the dual pathway model]] [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-implication|Beyond the dual pathway model]]

**Clinically tempting and measurement-poor.** Working-memory tasks are sensitive to prefrontal state and load, which makes them attractive as objective markers; but span tasks, n-back tasks and self-report scales measure different things and correlate modestly with each other and with everyday function, so a single 'working memory score' hides task, strategy and motivation differences and should be treated with caution. The clinical literatures that cite working-memory deficits - ADHD especially - inherit exactly these measurement qualifications. [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-implication|Beyond the dual pathway model]] [[Attention and executive function]]

**Reading rule.** Name the task, the load, the manipulation required and the population - naming them is what makes the claim interpretable; a working-memory difference can reflect storage, control, strategy or motivation, and the four are not distinguished by a single score. [[F09 Noba Research designs#^f09-limit|Research Designs]] [[P19621976 Arnsten 2009 Prefrontal catecholamines and ADHD#^p19621976-caution-transfer|AI appraisal: Prefrontal catecholamines and ADHD]]

## Evidence and status

Capacity limits are among the most replicated findings in psychology; the neural implementation and the mapping from tasks to everyday function remain contested.
