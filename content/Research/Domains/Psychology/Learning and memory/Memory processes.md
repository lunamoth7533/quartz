# Memory processes

**Definition.** Memory is described in three processes - encoding, storage and retrieval - each with its own failure modes. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]

## Supported claims

- Failure at encoding, storage or retrieval produces different problems. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]
- Retrieval depends on cues and context, so availability is not accessibility. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory (Encoding, Storage, Retrieval)]]
- Remembering is reconstructive: a confident recall can still be inaccurate. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory (Encoding, Storage, Retrieval)]]

## How it works

**Stages and stores.** Memory is described through encoding, storage and retrieval, with sensory, short-term and long-term stores distinguished in the same framework by capacity and duration. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]] Working memory adds active manipulation and executive control to short-term storage, which is why load and rehearsal affect performance. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

**The failure-mode taxonomy is diagnostic.** A failure at any stage produces the same complaint from the outside, which is why the distinction is diagnostic rather than academic. Because encoding, storage and retrieval are separable, different failures have different signatures: information never encoded cannot be cued out; degraded storage degrades with delay; retrieval failure responds to cues and context changes without any new learning. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]

**Cues and context gate access.** Forgetting has several distinct mechanisms, and because retrieval depends on cues and context, material that cannot be recalled may still be recognisable and reinstating the encoding context improves retrieval. That asymmetry is the basis for mnemonics and for the observation that 'forgetting' often reflects retrieval failure. [[F41 OpenStax Psychology 2e how memory functions#^f41-retrieval|How Memory Functions]] [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding, storage and retrieval]]

**Recall is reconstructive.** Remembering rebuilds an event rather than replaying it, which is why confident recall can be inaccurate; this is the finding behind the caution about eyewitness certainty and about the confidence with which people report their own histories. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding, storage and retrieval]]

**Systems.** Different memory types - episodic, semantic, procedural, working - depend on partially different circuits, which is why hippocampal damage affects new episodic learning while leaving other abilities relatively intact. [[F61 Neuroscience Online hippocampus#^f61-memory|Hippocampus]]

**Practice conditions change durability.** The taxonomy explains why testing yourself - a retrieval manipulation - improves later performance more than re-reading, an encoding manipulation: practice that exercises retrieval strengthens the pathway that will be needed. The same total study time distributed across sessions also produces more durable retention than massed study, an effect about storage and consolidation dynamics rather than motivation. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]] [[P37615780 Trumble 2024 Distributed and retrieval practice review]]

**How settled the practice effects are.** Spacing and retrieval practice are among the most robustly replicated learning techniques, though effect sizes depend on the outcome measured. [[P37615780 Trumble 2024 Distributed and retrieval practice review#^p37615780-results|Distributed and retrieval practice review]] Distributed practice is one of the largest and best-replicated effects in the learning literature, and it generalises across materials and ages - which makes it one of the few educational claims this library treats as close to settled. [[P37615780 Trumble 2024 Distributed and retrieval practice review]] In the health-professions education studies reviewed, spacing and retrieval practice - distributing study and testing recall - improved retention relative to massed rereading, with effects appearing in most experiments, and time on task and assessment stakes were flagged as confounders to track. [[P37615780 Trumble 2024 Distributed and retrieval practice review#^p37615780-results|Distributed and retrieval practice review]] [[P37615780 Trumble 2024 Distributed and retrieval practice review#^p37615780-confounders|Distributed and retrieval practice review]] [[P37615780 Trumble 2024 Distributed and retrieval practice review#^p37615780-caution-transfer|AI synthesis: Distributed and retrieval practice review]]

**Reading rule.** Memory claims should name the process, the material and the test. Confidence, accuracy and accessibility are three different measurements that routinely disagree. [[F11 Noba Memory encoding storage retrieval#^f11-limit|Memory encoding, storage and retrieval]]

**Cross-domain connection (curation).** Neurobiology supplies the consolidation substrate that makes distributed practice work - memory traces stabilise over time and sleep - so the psychological effect and the cellular story are two levels of one account rather than rivals. [[Synapses and plasticity]] [[Circadian rhythms and sleep]]

## Limitation or common misconception

Confidence is not a reliable index of accuracy, which complicates any notes system that treats recollection as record.
