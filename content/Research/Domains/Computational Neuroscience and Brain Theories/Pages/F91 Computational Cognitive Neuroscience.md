# Computational Cognitive Neuroscience (5th edition)

**Publisher.** O'Reilly, Munakata, Frank, Hazy and Contributors

**Source.** <https://book.compcogneuro.org/>

**Verification.** text opened and checked on 2026-09-25; retrieval saved as `receipts/source-checks/F91.txt`. Educational or official reference material, not primary research.

## Key points (as published)

The book builds models at levels from individual neurons to networks, using simulations to test whether a mechanism can reproduce a cognitive phenomenon.
^f91-levels

Learning rules and network architectures are presented as hypotheses about how biological circuits support memory, categorisation and control.
^f91-learning

The text distinguishes what a model demonstrates computationally from what it establishes about the biological system, which is the standard caveat for modelling work.
^f91-limits

## Scope and limitations

An open textbook on computational cognitive neuroscience. It teaches modelling practice and does not report new empirical findings.
^f91-limit
