# Episodic memory

## Definition

Episodic memory is memory for specific events with a sense of when and where they occurred, distinguished from semantic memory for facts and from procedural memory for skills.

## How it works

**Encoding.** Depth of processing at encoding predicts later recall better than repetition, which is why elaborative encoding is emphasised. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]]

**Retrieval.** Recall depends on cues and context: availability is not the same as accessibility, and matching encoding and retrieval conditions improves performance. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]]

**Reconstruction.** Remembering is reconstructive, so confident recall can be inaccurate; this is the basis for concern about eyewitness testimony and for therapy practices that shape memory. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]

**Neural basis.** The hippocampal system is critical for forming new episodic memories, shown most clearly by the consequences of damage. [[F61 Neuroscience Online hippocampus#^f61-memory|Hippocampus]]

## Evidence and status

Effects of encoding and retrieval manipulations are robust; the boundary between episodic and semantic memory is conceptually useful but not a clean neural division.

> [!info]- In depth: memories for events, and how confident reconstruction misleads
> **The stages and stores.** Memory is described through encoding, storage and retrieval with sensory, short-term and long-term stores, and episodic memory is the long-term system for personally experienced events, distinguished from semantic and procedural memory by what is stored rather than by how long it lasts. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]] [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory encoding storage retrieval]]
>
> **Retrieval is cue-dependent and reconstructive.** Retrieval depends on cues and context, so availability is not the same as accessibility, and remembering is reconstructive: recall can be confident and still inaccurate. Those two properties together explain why a vivid memory is not evidence of accuracy. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]
>
> **The hippocampal link.** Patient and animal evidence links hippocampal damage to memory impairment, and special properties of hippocampal circuits are used to explain why the system is suited to rapid, one-trial encoding of events. That evidence is largely from case studies and animal work, so it constrains the mechanism rather than describing any individual's memory. [[F61 Neuroscience Online hippocampus#^f61-memory|Hippocampus]] [[F61 Neuroscience Online hippocampus#^f61-limit|Hippocampus]]
>
> **Where this matters clinically.** Because memory is reconstructive, techniques that elaborate or suggest content deserve scepticism about the confidence they produce, and the trauma-memory literature's two overclaims - perfect flashbulb recall and wholesale unreliability - are both unsupported by the evidence described in this library. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]] [[P23047775 Pitman 2012 Biological studies of PTSD#^p23047775-layers|Biological studies of PTSD]]
>
> **Reading rule.** Separate what was encoded, what is accessible now, and what the person reports; only the third is directly observable, and it is a reconstruction each time it is produced. [[F11 Noba Memory encoding storage retrieval#^f11-limit|Memory encoding storage retrieval]] [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]]

> [!info]- Further depth: event memory and the confidence problem
> Episodic memory is the long-term system for personally experienced events, distinguished from semantic and procedural memory by what is stored rather than by duration, and retrieval depends on cues and context so availability is not accessibility. Because remembering is reconstructive, a confident recollection can be inaccurate, and the trauma-memory literature's two overclaims - perfect flashbulb recall and wholesale unreliability - both outrun the evidence. Hippocampal damage impairs memory, and the circuit's special properties are used to explain rapid one-trial encoding. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]] [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]] [[F61 Neuroscience Online hippocampus#^f61-memory|Hippocampus]]
>
> **Why the reconstruction claim is not scepticism.** Recall rebuilds an event from fragments plus schema, so it is sensitive to suggestion, to later information and to the context of retrieval. That is a functional design - reconstruction fills gaps faster than a verbatim store could - and its costs are measurable: confident false memories can be installed under controlled conditions, and confidence tracks the reconstruction's coherence rather than its accuracy. The claim is about mechanism, and it carries no implication that any particular memory is false. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory (Encoding, Storage, Retrieval)]]
>
> **What episodic distinctiveness buys.** The system binds what happened with where and when, which supports rapid one-trial learning of unique events - the adaptive problem a semantic store, which aggregates across episodes, cannot solve. The binding account is why hippocampal damage produces the specific pattern it does: new episodic learning fails while older semantic knowledge and skills survive.
