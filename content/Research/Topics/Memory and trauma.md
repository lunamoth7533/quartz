# Memory and trauma

## Definition

Memory for traumatic events is studied through clinical samples, prospective cohorts and laboratory models. It is a research area where strong claims in both directions - perfect flashbulb recall versus wholesale unreliability - outrun the evidence.

## How it works

**Reconstruction.** Remembering is reconstructive in general, so recall can be confident and inaccurate; this applies to emotional events as well as ordinary ones. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]

**Fragmentation claims.** The idea that trauma memory is stored in a qualitatively different, dissociated form is widely repeated but not consistently supported by evidence; memory for traumatic events is usually at least as accurate as for neutral events for the central details, with more fragmentation for peripheral detail.

**Dissociation.** Depersonalisation and derealisation are recognised features of a trauma-related subtype, and they affect encoding and retrieval; they are symptoms rather than proof of memory mechanisms. [[P22431063 Lanius 2012 Dissociative subtype of PTSD#^p22431063-definition|The dissociative subtype of PTSD]]

**Clinical implication.** Because memory is reconstructive, therapeutic techniques that elaborate or suggest content deserve scepticism about the confidence they produce.

## Evidence and status

Prospective studies of documented events provide the strongest evidence; retrospective clinical samples cannot distinguish memory properties from sampling effects.

> [!info]- In depth: what is actually documented about memory for traumatic events
> **Memory is reconstructive in general.** Memory is described through encoding, storage and retrieval, each with its own failure modes; retrieval depends on cues and context, so availability is not the same as accessibility; and remembering is reconstructive, meaning recall can be confident and still inaccurate. Those properties apply to emotional events as well as ordinary ones, and they are the background against which trauma-specific claims should be read. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]
>
> **Two overclaims, in opposite directions.** The idea that trauma memory is stored in a qualitatively different, dissociated form is widely repeated but not consistently supported. The complementary overclaim - that traumatic memories are wholesale unreliable - is also not supported, because memory for traumatic events is usually at least as accurate as memory for neutral events for central details, with more fragmentation reported for peripheral detail. Both statements are claims about average patterns in specific samples, not about any individual recollection. [[P23047775 Pitman 2012 Biological studies of PTSD#^p23047775-layers|Biological studies of PTSD]]
>
> **Where dissociation enters.** Depersonalisation and derealisation are recognised features of a trauma-related subtype supported by latent class analyses in veteran and civilian samples, and they affect encoding and retrieval. They are symptoms with assessment implications, not proof of a memory mechanism - and the subtype was proposed through antecedent, concurrent and predictive evidence assembled in a review, with differential-response evidence still developing. [[P22431063 Lanius 2012 Dissociative subtype of PTSD#^p22431063-definition|The dissociative subtype of PTSD]] [[P22431063 Lanius 2012 Dissociative subtype of PTSD#^p22431063-validators|The dissociative subtype of PTSD]] [[P22431063 Lanius 2012 Dissociative subtype of PTSD#^p22431063-implication|The dissociative subtype of PTSD]]
>
> **Dissociation is also a differential, not a conclusion.** The professional overview of dissociative disorders stresses the differential from trauma- and stressor-related presentations and from neurological and substance-related causes, because dissociative symptoms are non-specific. Self-report measures of dissociation correlate modestly with interview measures, and both can be influenced by the context of assessment, so a dissociation score does not by itself establish what a memory did. [[F85 MSD Manual Dissociative disorders#^f85-differential|Overview of Dissociative Disorders]] [[F85 MSD Manual Dissociative disorders#^f85-group|Overview of Dissociative Disorders]]
>
> **What the strongest designs can establish.** Prospective studies of documented events are the design that can distinguish memory properties from sampling effects; retrospective clinical samples cannot, because who presents for trauma-focused assessment is itself selected. That asymmetry is why the field's claims are strongest about central-detail accuracy in documented-event cohorts and weakest about the mechanisms by which individual memories are organised.
>
> **Clinical implication.** Because memory is reconstructive, therapeutic techniques that elaborate or suggest content deserve scepticism about the confidence they produce - the practical issue is not whether a memory feels vivid but whether anything independent corroborates it. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]
>
> **Consolidation and reconsolidation are where the clinical questions live.** Memory for an event stabilises over time through consolidation, and retrieval returns a memory to a labile state that reconsolidates with new information - which is why techniques applied during or after retrieval can change what a memory becomes. That property is what trauma-focused therapy exploits deliberately and what suggestive interviewing can exploit accidentally; the difference between the two is not the mechanism but the intent and the corroborating context. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]] [[P23047775 Pitman 2012 Biological studies of PTSD#^p23047775-layers|Biological studies of PTSD]]
