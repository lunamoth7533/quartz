# Memory processes

**Definition.** Memory is described in three processes - encoding, storage and retrieval - each with its own failure modes. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]

## Supported claims

- Failure at encoding, storage or retrieval produces different problems. [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]
- Retrieval depends on cues and context, so availability is not accessibility. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory (Encoding, Storage, Retrieval)]]
- Remembering is reconstructive: a confident recall can still be inaccurate. [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory (Encoding, Storage, Retrieval)]]

## Limitation or common misconception

Confidence is not a reliable index of accuracy, which complicates any notes system that treats recollection as record.
