# Explorer order

The `sorting-spec` property above is read by the Custom File Explorer sorting plugin. Each `target-folder:` line starts a folder's order; names are listed first-to-last and `...` stands for everything not named. Domains follow [[Research Atlas]]; inside a domain the map comes first, then its subdomains in concept-register order, then `Articles` and `Pages`.
