# Research Atlas

This is the reference entry point. The library has two layers: a **reference encyclopedia** (this layer) organised into fifteen domains of concept articles backed by canonical source records, and a **learning layer** under `Learning/` that sequences material for study. The reference layer answers "what is this and how does it work"; the learning layer answers "in what order should I meet it".

Everything here is educational reference material. It is not a diagnosis, a treatment plan, or a source of dosing guidance.

## Concept articles

Browse concepts as structures, processes, mechanisms, theories, methods, conditions or frameworks. Each concept has one main article; domain hubs link to that article so you can follow an idea across fields without losing its source trail.

- [[Reference Index]] - dynamic A-Z, by domain, by concept kind, by condition, and by evidence route.
- [[Reference Index.base|Reference tables]] - filter and sort the same concepts and sources in native tables.

## Sources and evidence

Source records live in each domain's `Articles/` and `Pages/` folders, filed once under the source's own `domain`, one record per canonical paper, page or dataset, each with short statements that carry block anchors. Topics link to those anchors so a claim can be traced to the block that supports it. The `access_level` field says what was actually available (full text, abstract, public page), and `verification` records what was checked.

- [[Library]] explains how to read the source records.
- [[Visualizations]] holds the operational dashboards.

## Relationships between domains

Cross-domain relationships are stated in the articles themselves with explicit vocabulary - part of, projects to, regulates, measures, is associated with, contrasts with. The curated register lives in [[Reference Index#Relationship register|the reference index]], where each entry names the relation type and the hub that develops it. A link is a route to an explanation, never evidence of causation.

## How to use this layer

1. Start from a domain hub if you know the field you need.
2. Use [[Reference Index]] if you know a term, a condition or a concept kind.
3. Follow source links when a claim matters; read the anchor block rather than the whole record.
4. Treat the learning layer as a separate, slower route through the same material: [[Learning Hub]], [[Learning Path]], [[Learning Dashboard]].
