# Mechanisms of Neurotransmitter Release

## Key points (as published)

Calcium entry into the presynaptic terminal is a key step in chemical transmission, established in classic experiments at the skeletal neuromuscular junction.
^f115-calcium

Transmission occurs in quantal units, which is the evidence base for the vesicle-release model of transmitter release.
^f115-quanta

Release depends on both calcium availability and the state of the release machinery, so the same action potential can produce different amounts of transmitter.
^f115-requirements

## Scope and limitations

A textbook chapter on release mechanisms, based on classical electrophysiology at the neuromuscular junction.
^f115-limit
