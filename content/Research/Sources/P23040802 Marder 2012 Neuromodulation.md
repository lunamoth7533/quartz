## Reported findings (checked full text)

Neuromodulators change the properties of neurons and synapses in a circuit, so the same anatomical network can produce different functional outputs.
^p23040802-reconfigure

Circuits with different underlying parameters can produce similar outputs, which the review treats as a fundamental problem for relating structure to function.
^p23040802-degeneracy

Because modulation depends on the current state of the circuit, a transmitter's effect cannot be summarised without knowing the state in which it acts.
^p23040802-state

## Scope as reported

A review of circuit-level neuromodulation, drawing heavily on crustacean and vertebrate preparations. It makes a conceptual rather than clinical argument.
