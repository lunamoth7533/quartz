## Key points (as published)

Reinforcement learning formalises how an agent learns from reward signals to choose actions, with value functions and policies as central objects.
^f123-framework

Temporal-difference learning updates value estimates from the difference between predicted and observed outcomes, a quantity that maps onto prediction-error signals in the brain.
^f123-td

The framework treats exploration and exploitation as an explicit trade-off, which is one reason it is used as a computational language for adaptive behaviour.
^f123-exploration

## Scope and limitations

A technical textbook landing page; the full text is distributed separately as a free PDF. The framework is a formal model, not a claim about any specific neural implementation.
