# Working memory

**Module.** M04 Psychology · **Topic.** [[Working memory]]

## Why this matters

"Working memory deficit" is one of the most frequently cited findings in this vault's clinical domains, especially ADHD - and one of the easiest to over-read, because span tasks, n-back tasks and self-report scales measure different things and agree only modestly. Knowing what working memory names protects against treating a single score as one capacity.

## The core model

Working memory is the limited-capacity system that holds information active while it is used - it includes storage and manipulation, unlike older short-term store models. Holding a number in mind is a short-term-store task; using it in a calculation while holding it is a working-memory task. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

Capacity limits are usually pictured as a fixed number of storage slots, but the evidence favours a different account: performance declines steeply as load increases mainly because representations compete and blur, not because slots fill up. Similar items interfere faster than dissimilar ones, and new representations take time to consolidate, during which further input can disrupt them - predicting a counterintuitive pattern (fewer, simpler items can be more reliable than many precise ones) and tying capacity to control as well as raw storage. [[F41 OpenStax Psychology 2e how memory functions#^f41-working|How Memory Functions]]

Updating what is held, inhibiting irrelevant content, and shifting between tasks are separable executive operations, not one unified faculty. In one influential account of ADHD's cognitive profile, temporal processing, inhibitory control and delay-related deficits behaved as independent components - so a group difference on one working-memory task need not reflect a general capacity limit. [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-finding|Beyond the dual pathway model]] [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-implication|Beyond the dual pathway model]]

That independence is also why working memory is measurement-poor even though it looks objective: span tasks, n-back tasks and self-report scales correlate only modestly with each other and with everyday function, so a single "working memory score" can hide differences in storage, control, strategy and motivation - a caution any clinical literature citing a working-memory deficit inherits. [[P20410727 Sonuga-Barke 2010 Beyond the dual pathway#^p20410727-implication|Beyond the dual pathway model]]

A 2024 meta-analysis makes the transfer problem concrete: across 52 comparisons, training improved performance on the trained task, much less on tasks that merely resembled it, and did not improve fluid intelligence at all. Task similarity was the largest source of bias identified, so a training gain mostly measures practice with that format rather than a general capacity increase. [[P38366265 Rodas 2024 Bias in working memory training#^p38366265-effect|Rodas 2024]] [[P38366265 Rodas 2024 Bias in working memory training#^p38366265-transfer|Rodas 2024]] [[P38366265 Rodas 2024 Bias in working memory training#^p38366265-bias|Rodas 2024]]

## Worked example (hypothetical)

This scenario is invented for practice. A brain-training app advertises that its working-memory game "improves your working memory", citing a study where users' scores on that same game rose 40% over eight weeks.

Ask the transfer question first: did the study measure a different working-memory task, or only the trained game? Rising scores on the trained task alone are consistent with practice on that format, the largest source of apparent improvement the 2024 meta-analysis found. Ask whether any far-transfer measure, such as fluid intelligence, was included and moved. If the only evidence is same-task improvement, the accurate claim is "users got better at this game", not that working memory improved generally.

## Common confusions

- "Working memory is a set number of storage slots." Capacity limits are better explained by interference between representations than by a fixed slot count.
- "A working-memory score is one thing." Span, n-back and self-report measures correlate only modestly with each other, so a single score can mean different things.
- "Working-memory training improves general cognition." Gains are largest on the trained task and shrink sharply for tasks that only resemble it.

## What the sources do not establish

The sources describe reliable capacity effects and a well-documented transfer problem in training studies; they do not identify one neural mechanism common to every working-memory task, and they do not support treating any single task score as a general measure of a person's working-memory capacity.
