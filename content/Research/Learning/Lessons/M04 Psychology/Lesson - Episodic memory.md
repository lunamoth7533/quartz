# Episodic memory

**Module.** M04 Psychology · **Topic.** [[Episodic memory]]

## Why this matters

Episodic memory is the system behind every autobiographical claim in this vault's condition domains - what someone remembers happening, and when. It is also the system most vulnerable to a specific illusion: a memory can feel completely accurate and still be a reconstruction shaped by what happened after the event. Understanding why protects against treating vividness or confidence as evidence of accuracy.

## The core model

Episodic memory is memory for specific events with a sense of when and where they occurred, distinguished from semantic memory for facts and from procedural memory for skills - a distinction based on what is stored, not on how long it lasts. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]] [[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory encoding storage retrieval]]

At encoding, depth of processing predicts later recall better than repetition does - thinking about what something means helps more than repeating it unchanged, which is why elaboration is emphasised over rote exposure. [[F41 OpenStax Psychology 2e how memory functions#^f41-three|How Memory Functions]]

What makes episodic memory distinctive is binding: the system ties together what happened with where and when, supporting fast, one-trial learning of a unique event - something a semantic store, which aggregates across episodes, cannot do. This also explains a clinical pattern: when the hippocampal system is damaged, new episodic learning fails while older semantic knowledge and skills survive, because the binding machinery for new events is gone while facts already stored elsewhere remain intact. [[F41 OpenStax Psychology 2e how memory functions|How Memory Functions]] [[F61 Neuroscience Online hippocampus#^f61-memory|Hippocampus]]

Retrieval is cue-dependent: recall depends on the cues and context available at the moment of remembering, so availability is not the same as accessibility. Information can be stored and still unreachable until the right cue appears, and matching encoding and retrieval conditions improves performance. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]]

The most consequential property is that remembering is reconstructive: recall rebuilds an event from fragments plus general knowledge of how such events usually go, making it sensitive to suggestion and later information. Confident recall can be inaccurate - not because memory is broken, but because reconstruction fills gaps faster than a verbatim recording could, and confidence tracks how coherent the reconstruction feels, not how accurate it is. Confident false memories have been installed experimentally, which is why a vivid memory is not, by itself, evidence of what happened - a claim about mechanism, not that any particular memory is false. [[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory encoding storage retrieval]] [[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory (Encoding, Storage, Retrieval)]]

## Worked example (hypothetical)

This scenario is invented for practice. Two witnesses to the same brief event give confident, detailed, but different accounts weeks later.

Do not treat confidence as a tiebreaker - it is only loosely related to accuracy in reconstructive recall. Ask instead what happened between the event and the retelling: did either witness discuss it with others, see media coverage, or get asked leading questions that could supply new "fragments"? Ask what cues were available at each retelling, since a different question can steer which details get rebuilt. The reasoned conclusion is not "one witness is lying" but that both accounts are reconstructions, and their disagreement is what the mechanism predicts - which is why corroborating evidence, not confidence, should settle the factual question.

## Common confusions

- "A vivid, confident memory is an accurate one." Confidence tracks the coherence of a reconstruction, not its accuracy.
- "Forgetting means information is gone." Often it is stored but inaccessible until the right retrieval cue is present.
- "Hippocampal damage erases all memory." It disrupts new episodic learning specifically, while semantic knowledge and skills already established elsewhere can survive.

## What the sources do not establish

The hippocampal evidence is largely from case studies and animal work, so it constrains the general mechanism rather than describing any individual's memory, and the sources do not settle a clean neural boundary between episodic and semantic memory - the distinction is conceptually useful but not a sharp division in the brain.
