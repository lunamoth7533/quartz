# Memory processes

**Module.** M04 Psychology · **Topic.** [[Memory processes]]

## Why this matters

This vault is a memory system: it exists because recollection is unreliable. The psychology of memory explains
why notes, anchors and provenance are not bureaucratic extras, and it changes how you treat your own
recollections of what you read.

## The core model

Memory is described in three processes — encoding, storage and retrieval — each with its own failure modes.
[[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory (Encoding, Storage, Retrieval)]]

Retrieval depends on cues and context, so availability is not the same as accessibility: information can be
stored and still unreachable until the right cue appears.
[[F11 Noba Memory encoding storage retrieval#^f11-cues|Memory (Encoding, Storage, Retrieval)]]

Remembering is reconstructive: recall can be confident and still inaccurate.
[[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory (Encoding, Storage, Retrieval)]]

Those three claims organise a practical routine. Encoding failures suggest that attention and elaboration were
insufficient; storage and consolidation failures suggest spacing and sleep matter; retrieval failures suggest
that the problem is cueing, which is why retrieval practice and varied contexts help. And the reconstruction
finding explains why a vivid memory is not evidence about what actually happened.

This model also explains why retrieval practice is more than testing. Producing an answer from memory means
reconstructing it from cues, and the reliable behavioural finding is that this effort usually improves later
retention compared with rereading, which mostly strengthens recognition of the text in front of you. The
theoretical accounts — elaborative retrieval, reconstruction, and the idea that successful attempts strengthen
the routes they use — are explanatory accounts of that finding, not a single demonstrated neural route that is
strengthened on every successful recall. What the evidence supports is the routine in [[Study Workflow]]: the
effort of retrieval is the intervention, not just a measurement of it.

## Worked example (hypothetical)

This scenario is invented for practice. You remember a study reporting a large effect for a therapy, but you
cannot find it when you search the vault, and you are confident you read it.

Diagnose the failure. Was the claim encoded with the details — authors, year, outcome — or only as the gist of
"something showed a big effect"? If the gist is stored without the source, retrieval will produce a confident
reconstruction and fill in the missing parts plausibly. The cue (your memory of the topic) is not sufficient to
recover the source.

The routine response is the same as this vault's rule: do not keep the claim as a memory. Write it as a question
with what you can recall, and mark it unsourced until a source block supports it. If it mattered, the
reconstruction will have a hook to search from.

## Common confusions

- "Confidence tracks accuracy." It often does not, especially for details.
- "Forgetting is one thing." Encoding, storage and retrieval failures look different and need different fixes.
- "Notes are only for storage." They are also cues: a good note creates retrieval paths.

## What the sources do not establish

The teaching source gives a general model and does not address individual differences, clinical memory problems
or forensic accuracy. Specific claims about any condition's memory profile would need clinical evidence, which
this vault does not currently hold.
