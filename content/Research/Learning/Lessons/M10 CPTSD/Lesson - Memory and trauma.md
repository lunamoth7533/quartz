# Memory and trauma

**Module.** M10 CPTSD · **Topic.** [[Memory and trauma]]

## Why this matters

Popular claims about trauma memory run to two opposite extremes - perfectly preserved recall, or wholesale
unreliability. Both outrun the evidence. The accurate, more boring middle position matters directly, because
intrusive memory is a core symptom in both PTSD manuals covered in this module.

## The core model

**Memory is reconstructive in general.** Memory is described through encoding, storage and retrieval, each with
its own failure modes; retrieval depends on cues and context; and remembering is reconstructive, meaning recall
can be confident and still inaccurate. These properties apply to emotional and ordinary memories alike, and are
the background against which any trauma-specific claim should be read.
[[F11 Noba Memory encoding storage retrieval#^f11-stages|Memory encoding storage retrieval]]
[[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]

**Two overclaims, opposite directions.** That trauma memory is stored in a qualitatively different, dissociated
form is widely repeated but not consistently supported. The opposite claim - that traumatic memories are
wholesale unreliable - is also not supported: memory for traumatic events is usually about as accurate as for
neutral events for central details, with more fragmentation for peripheral detail. Both statements describe
average patterns in specific samples, not any one person's recollection.
[[P23047775 Pitman 2012 Biological studies of PTSD#^p23047775-layers|Pitman 2012]]

**Where the clinical questions live.** A memory stabilises through consolidation, and retrieval returns it to a
changeable state that reconsolidates with new information - which is why techniques applied during retrieval can
genuinely change what a memory becomes. That property is what trauma-focused therapy deliberately uses, and what
suggestive interviewing can exploit by accident; the difference is intent and corroboration, not the mechanism.
[[F11 Noba Memory encoding storage retrieval#^f11-reconstructive|Memory encoding storage retrieval]]

**Where dissociation enters.** Depersonalisation and derealisation are recognised features of a trauma-related
subtype, affecting encoding and retrieval - symptoms with assessment implications, not proof of a memory
mechanism.
[[P22431063 Lanius 2012 Dissociative subtype of PTSD#^p22431063-definition|Lanius 2012]]
Dissociative symptoms are also non-specific: a professional overview stresses the differential from
trauma-related, neurological and substance-related causes, and self-report measures of dissociation correlate
only modestly with interview measures. A dissociation score does not, by itself, establish what a memory did.
[[F85 MSD Manual Dissociative disorders#^f85-differential|Overview of Dissociative Disorders]]

**Clinical implication.** Because memory is reconstructive, techniques that elaborate or suggest content deserve
scepticism about the confidence they produce - the question is not vividness, but independent corroboration.

## Worked example (hypothetical)

This scenario is invented for practice. A hypothetical talk-show guest claims: "Because trauma memories are
stored differently, a guided technique can retrieve the exact, accurate details of a forgotten memory."

Take the claim apart. The first half repeats the unsupported "different storage" idea. The second half draws, in
reverse, on a real mechanism: retrieval can change a memory through reconsolidation, which is why a guided or
suggestive technique can shift what someone recalls, and why vividness produced under suggestion is a reason for
caution, not extra confidence. The useful question is not "how vivid did it feel," but "what, independent of the
session itself, corroborates this."

The accurate rewrite: the claim conflates an unsupported storage idea with a real but double-edged property of
retrieval, and neither half licenses treating a retrieved memory as verified without corroboration.

## Common confusions

- "Trauma memories are stored in a totally different way." Not consistently supported by the evidence cited
  here.
- "A vivid, confident memory must be accurate." Memory is reconstructive; vividness and confidence are not the
  same as accuracy.
- "Any dissociative symptom during recall confirms the memory's content." Dissociative symptoms are non-specific
  and call for a differential assessment, not automatic confirmation.

## What the sources do not establish

How dissociation at encoding affects later recollection is not well characterised in prospective designs. A
newer theory linking memory and identity to complex PTSD has had only its first, cross-sectional test, so its
causal claims still await prospective replication.
[[P37338431 Hyland 2023 Memory and identity theory of CPTSD#^p37338431-caution-untested|Appraisal: Hyland 2023]]

## Check yourself

1. What does it mean to say memory is "reconstructive"?
2. What are the two opposite overclaims about trauma memory, and what does the evidence support instead?
3. Why is a dissociative symptom during recall not, by itself, proof of a memory's content?

## Answer notes

1. That recall is rebuilt from stored fragments and retrieval cues rather than played back, so it can be
   confident and still inaccurate.
2. That trauma memory is stored differently, and that it is wholesale unreliable; central-detail memory for
   traumatic events is usually about as accurate as for neutral events.
3. Dissociative symptoms are non-specific and require a differential assessment against other causes.
